# 보안 설명서 (비개발자용)

이 문서는 코드를 몰라도 이해할 수 있도록, 이 프로그램이 미공개 재무정보를
어떻게 보호하는지 설명합니다. 자세한 원본 요구사항은 `PROJECT_SPEC.md`에
있습니다.

## 1. Private Zone이 무엇인가

미공개 재무제표, 계정별 증감, 프로그램이 찾아낸 패턴, "왜?"라는 조사 질문,
회계사의 리뷰 코멘트 — 이 모든 것은 **Private Zone**에서만 존재합니다.
Private Zone은 여러분의 컴퓨터 안에서만 돌아가며, 인터넷에 연결된 적이
없습니다.

## 2. Public Zone이 무엇인가

이미 세상에 공개되어 있는 정보(회사명, DART 공시번호, 공개 뉴스기사 등)를
가져오는 역할만 하는 별도 영역입니다. 이 영역은 `app/public_data_collector/`
폴더 안의 코드에만 존재하며, 그 외 어떤 코드도 인터넷에 연결하지 않습니다
(아래 8번 참고).

## 3. 외부로 나가는 정보

사용자가 "공개자료 가져오기"를 눌렀을 때, 딱 이것만 외부(DART, 뉴스 API)로
전달됩니다:

- 공개 회사명
- DART corp_code
- 조회 시작일 / 종료일
- 페이지 번호

## 4. 외부로 절대 나가지 않는 정보

- 재무제표 수치, 증감률
- 프로그램이 찾아낸 Pattern(계정 간 관계, 이상 변동 등)
- 조사 질문(Investigation Question)
- 회계사가 남긴 리뷰/코멘트
- 업로드한 원본 파일 내용, 파일명

## 5. 회사명은 외부 API에 전달될 수 있다는 점

DART나 뉴스에서 관련 자료를 찾으려면 "어느 회사인지"는 알려줘야 합니다.
회사명 자체는 이미 공개된 정보이므로 이 프로그램의 보안 원칙에서 "미공개
정보"로 취급하지 않습니다. 다만 회사명 외의 어떤 것도 함께 나가지 않도록
아래 8~9번의 장치로 강제하고 있습니다.

## 6. Investigation Question은 Local에만 존재한다는 점

"생산시설 확대가 있었는가?" 같은 조사 질문은 내부 재무 패턴에서 자동으로
만들어지지만, 이 질문 자체가 Google/Naver/뉴스 API/DART/외부 AI에 검색어로
보내지는 일은 절대 없습니다. 대신 회사명과 기간만으로 관련 자료를 넓게
가져온 뒤, "이 자료가 조사 질문과 관련 있는가?"라는 판단은 여러분의
컴퓨터 안에서만 이루어집니다.

## 7. 재무수치는 외부로 전송되지 않는다는 점

`app/public_data_collector/schemas.py`의 `PublicCollectionRequest`는 처음부터
7개 필드(회사명, 식별자, corp_code, 조회기간, 페이지)만 받을 수 있게
만들어져 있습니다. 재무 수치를 넣을 자리 자체가 없습니다 — 코드 구조상
불가능합니다.

## 8. Public Data Collector 구조

인터넷에 연결하는 코드는 프로젝트 전체에서 `app/public_data_collector/`
폴더 안에만 있습니다. 이 사실은 매번 테스트를 돌릴 때마다 자동으로
재확인됩니다(`tests/test_public_data_collector.py`가 `app/` 전체 소스코드를
스캔해서, 그 폴더 밖에서 네트워크 관련 코드를 쓰면 테스트가 실패하도록
만들어져 있습니다).

## 9. Allowlist 방식

"이것만 빼고 다 보낸다"가 아니라 "이 7개만 보낼 수 있다"는 방식(Allowlist)을
씁니다. `network_guard.py`가 이 7개 외의 필드가 하나라도 섞이면 요청 자체를
막고 에러를 발생시킵니다(`SecurityException`). 이 검증은 실제 API 호출
직전에 항상 실행됩니다.

## 10. Local AI 구조

문서 검색에 쓰는 AI(문장 임베딩 모델)는 여러분이 직접 준비해 로컬 폴더에
넣어둔 모델만 사용합니다. 프로그램이 스스로 인터넷에서 모델을 내려받는
일은 없습니다. 모델이 없으면 기능이 꺼지고 "Local AI model is not
installed."라고 표시될 뿐, 다른 핵심 기능(재무비율, 계정 관계 분석 등)은
그대로 작동합니다.

## 11. Local RAG 구조

가져온 공개자료(기사, 공시)는 문단 단위로 쪼갠 뒤(Chunking), 위 10번의
로컬 AI로 벡터화하고, 조사 질문과의 유사도를 계산해 관련도 높은 순으로
보여줍니다. 이 전 과정이 여러분의 컴퓨터 안에서만 실행되며, 외부 LLM
API(OpenAI/Claude/Gemini 등)는 어디에서도 호출하지 않습니다.

## 12. PostgreSQL 구조

분석 결과와 리뷰 기록은 여러분 컴퓨터에 설치된 PostgreSQL(127.0.0.1)에만
저장됩니다. 클라우드 데이터베이스는 코드 차원에서 아예 거부하도록
만들어져 있습니다 — `DATABASE_URL`이 localhost가 아니면 프로그램이 실행을
거부합니다.

## 13. Claude Code 개발 시 실제 고객자료 사용 금지

이 프로그램은 Claude Code(외부 AI 개발 도구)로 개발되었습니다. 개발
과정에서는 실제 미공개 재무제표나 고객자료를 절대 사용하지 않고, 가상의
회사(ABC Manufacturing, Sample Electronics)로 만든 테스트용 데이터만
사용했습니다.

## 14. 현재 보안 구조의 한계

- 아직 실제 DART/뉴스 API 연결은 사용자가 발급받은 키가 있어야 동작합니다
  (`SETUP_POSTGRESQL.md`처럼 별도 안내 필요 — API 키 발급 방법은 `.env`
  파일의 주석을 참고하세요).
- Windows 로그인 계정 자체가 뚫리거나, PC에 물리적으로 접근당하는 경우
  이 프로그램의 보안 설계로는 막을 수 없습니다(OS/디스크 암호화 수준의
  보안은 별도 사안입니다).
- 개발/테스트 단계의 코드이며, 정식 보안 감사를 받지 않았습니다.

## 15. 실제 기업에서 사용하려면

실제 회사의 미공개 재무자료를 다루기 전에, 반드시 소속 회사의 정보보안팀
검토와 승인을 받아야 합니다. 이 프로그램의 설계 원칙은 "내부정보를 외부로
보내지 않는다"는 것이지만, 실제 운영 환경에서는 접근권한 관리, 백업,
감사로그 등 추가적인 보안 정책이 필요합니다.
